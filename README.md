## Xhopii - Aplicação Web
sobre o projeto
Xhopii é uma aplicação web desenvolvida como um trabalho prático para a disciplina de Programação Web Mobile. O projeto implementa funcionalidades de cadastro e autenticação de usuários, bem como cadastro de produtos, simulando uma plataforma de e-commerce.

## 🚀 Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:

Backend: PHP

Frontend: HTML, CSS

Banco de Dados: MySQL

## ⚙️ Instalação e Execução
Para rodar este projeto localmente, siga os passos abaixo:

Pré-requisitos
Um ambiente de servidor local como XAMPP ou WAMP.

Git (opcional, mas recomendado).

Passos
Clone o repositório:

Bash

git clone https://github.com/jvdragon05/Xhopii.git
Caso não tenha Git, você pode baixar o projeto como um arquivo ZIP e extraí-lo.

Mova os arquivos do projeto: Mova a pasta Xhopii para o diretório htdocs (no XAMPP) ou www (no WAMP) do seu servidor local.

Configure o Banco de Dados:

Inicie os serviços do Apache e MySQL no seu painel de controle (ex: XAMPP Control Panel).

Acesse o phpMyAdmin através do seu navegador (geralmente em http://localhost/phpmyadmin).

Crie um novo banco de dados.

Importe o arquivo xhopii.sql para criar as tabelas e estruturas necessárias para a aplicação.

Acesse a aplicação: Abra o seu navegador e acesse http://localhost/Xhopii.
